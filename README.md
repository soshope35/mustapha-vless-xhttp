# VLESS XHTTP on Google Cloud Run

A lightweight Docker-based VLESS + XHTTP proxy powered by Xray-core, designed to run on Google Cloud Run.

# Features:

VLESS + XHTTP transport
Xray-core
Docker-based deployment
Google Cloud Run compatible
TLS termination through Cloud Run
GitHub Actions automated Docker builds
Public Docker image for easy deployment
